# Sprints 9-10 — Pulido y release

**Duración:** 3-4 semanas
**Objetivo:** app lista para closed testing.

## Tareas

- [ ] Performance: archivos grandes (50k+ líneas), repos con muchos archivos, cold start < 2s
- [ ] Onboarding de primer uso (crear proyecto o clonar de GitHub)
- [ ] Crash reporting + analytics mínimo (respetando privacidad)
- [ ] Pasar la checklist de accesibilidad táctil por todas las pantallas
- [ ] Closed testing en Play Store
- [ ] (Opcional) iOS: `npx cap add ios` y build de TestFlight con editor + git + GitHub (sin terminal)
- [ ] Página simple del proyecto (docs/website)

## Criterios de aceptación

1. 5 usuarios de prueba completan el flujo MVP sin ayuda.
2. Cero crashes conocidos en los flujos principales.
3. Publicada en closed testing con feedback loop claro.
